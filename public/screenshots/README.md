# App Screenshots Directory

Place your Android app screenshot PNG/JPG files in this folder:
- `home.png` -> Main home dashboard screenshot
- `notes.png` -> Notes / Study material screen
- `mock-test.png` -> Mock test & scorecard screen
- `pyqs.png` -> Previous Year Questions screen
- `quiz.png` -> Topic quiz & bilingual interface screen

You can customize these file names in `src/config/siteConfig.ts` under `APP_SCREENSHOTS`.
